O que é esta tela
⚙️
Ferramenta do Organizador
Gera e armazena o banco de cartelas que os jogadores usarão quando o evento for do tipo 'Banco de Cartelas'.
Como usar
1️⃣
Escolher Modo
Selecione G90 (90 pedras, cartela 5×9) ou G75 (75 pedras, cartela 5×5 com estrela livre).
2️⃣
Gerar Cartelas
Informe a quantidade desejada e clique em 'Gerar'. O sistema evita cartelas duplicadas ou muito semelhantes.
3️⃣
Visualizar
Role a lista para conferir as cartelas geradas. Clique em uma para ver os detalhes ou excluí-la individualmente.
4️⃣
Exportar
Use o botão 'Exportar' para baixar as cartelas em formato imprimível (PDF/JSON).
🗑️
Limpar Banco
'Limpar G90' ou 'Limpar G75' apaga todas as cartelas daquele modo. Irreversível.
Navegação
‹ ›
Paginação
Use os botões 'Ant / Próx' para navegar entre as páginas de cartelas.
📊
Contador
O topo mostra quantas cartelas estão armazenadas em cada modo.
💡
Gere cartelas antes de criar o evento. O banco fica salvo no Firebase e aparece automaticamente para os jogadores.
⚠️
Cartelas com números muito parecidos são automaticamente descartadas para garantir equilíbrio na partida.
